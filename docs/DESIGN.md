# VoiceCut 设计文档

## 1. 定位

面向 **GPT-SoVITS 日文训练**的音频采集 / 清洗 / 精切 / 转写 / 导出工具。
素材来源：本地视频音频、B 站直链流、动漫 / 歌曲 / 广播剧。**训练由用户自行完成**，本工具只负责产出高质量数据集。

## 2. 端到端工作流

```
素材(动漫/歌曲/广播剧)
  → ① 导入: 本地拖拽 / 网络 URL 批量导入(yt-dlp 多平台, 免登录低清, 页面预览+边看边缓存)
  → ② 清洗: 人声分离(demucs htdemucs GPU) / 保守降噪(noisereduce)
            / 去头尾静音 + 响度标准化
  → ③ 说话人: ECAPA 声纹嵌入 + 层次聚类 → 每段字幕/片段打上 speakerLabel → 角色池合并/命名/着色/试听/重定向
  → ④ 精切: 波形+视频同步, 实时字幕辅助定位(带说话人标记), 选区→片段列表(角色下拉/逐条试听/编辑/删除/跳转), 可自动按静音切分
  → ⑤ 转写: faster-whisper 批量转写(JP), 文本人工校对(质量天花板)
  → ⑥ 校验: 时长1~15s(主力2~8s) / 静音率 / 爆音 / 空文本 → 标红
  -> ⑦ 导出: GPT-SoVITS 标准目录 (001.wav + 001.txt + list.txt, 32kHz单声道, 语言JP, speaker=角色名)
```

## 3. 界面布局

参考剪辑软件（CapCut / Premiere / Audacity）布局语言 + **Blender 式自由工作区**：高频操作平铺、工具收纳进子菜单；5 个面板（素材列表 / 视频预览 / 波形 / 实时字幕 / 片段列表）在 3×3 网格槽位间自由排版，布局自动保存到 localStorage（窗口▸恢复默认布局）。

```

│  文件▸ 导入(Ctrl+O)/从URL导入/导出选区/新建项目/重命名项目/删除项目  │
│  音频▸ 降噪/分离人声/去静音                                        │

├──────────────────────────────────────────────────────────────┤
│ 高频按钮: [导入文件] [🔗从URL导入] [导出训练集]  ──项目下拉──      │
├─────────┬─────────────────────────┬─────────────────────────┤
```

工作区可自由排版（Blender 式）：
- 拖面板标题栏在 5 个槽位间交换；拖分隔条调整行/列大小（最小尺寸自动钳制）
- 面板右上角 × 或「窗口」菜单显隐，隐藏后其余面板自动伸展
- 布局自动保存（localStorage `vc.workspace.v1`），刷新后还原
- 传输栏固定在窗口底部（状态栏上方），菜单栏/工具栏/状态栏为固定 Chrome

波形交互（对齐剪辑软件习惯）：
- 左键拖拽拉框 = 选区（蓝底高亮）；选区两端手柄可拖边缘微调
- 播放头可拖动，点击时间轴任意位置跳转
- 滚轮以鼠标位置为中心缩放；底部总览条(minimap)可框选导航
- 波形区域内右键不弹浏览器菜单：有选区时取消选区，拖拽未松手时取消本次拖拽
- 视频预览窗与波形/播放头/选区双向联动：点波形/字幕→视频跟随；拖视频进度条/点视频播放暂停→波形跟随
- 实时字幕区：播放/拖动时高亮当前字幕行；点字幕行=设为选区，「加片段」带文本进片段列表；可加载 .srt/.ass、视频内嵌字幕自动提取，或用 Whisper 生成

## 4b. 角色池 / 说话人识别（M1-M3）

- 识别说话人：ECAPA-TDNN 声纹嵌入(speechbrain, 非 gated 模型，hf-mirror 下载) + scipy 层次聚类；模型加载失败时自动降级为 MFCC 聚类（quality=\"mfcc\"）。**每条字幕内部按 0.8s 滑窗(步进 0.4s)采样声纹再聚类**——whisper 把两人合成一句话时，窗口会自动把两个声纹拆进各自的簇，speaker_segments 以「窗口连续段」输出（比字幕更细），角色代表声纹只取各自簇的干净窗口均值，避免混音污染把两个角色并入一人。**片段绑定用 dominant_label**：一句话确实含两人（次标签覆盖≥35% 且≥0.25s）时标 mixed 且不自动绑定角色，供人工拆分/重定向；其余自动绑定。结果仍允许过/分割错误合并，靠角色池人工校正。
- 角色池：工具栏「角色池」进入全屏子页面；每个自动标签生成一个临时角色；可新建/重命名/修改颜色/删除/试听/合并(多选勾选)/拖拽片段重定向。
- 片段说话人：列表列为角色池下拉（含未分配），行左色条、字幕行标记角色颜色；多选行右键→重定向角色。
- 持久化：角色池为项目级共享，存入服务端 SQLite `workdir/voicecut.db`（项目/素材注册表同库），刷新/重启不丢；片段与 speaker_segments 仍按素材存储。
- 跨素材自动归并：ECAPA 识别时按声纹相似度（余弦 ≥ 0.82）把不同素材里的同一角色自动并入同一项目角色，标签以 "<素材id>:<标签>" 命名空间隔离；MFCC 降级时不自动归并，仍可人工合并/重定向校正。

## 4c. 素材与导入、总览条（M4-M6）

- 素材右键菜单：删除(二次确认) / 重命名 / 添加到工作区(设为当前选中，已在则置灰)。
- 网络 URL 导入：工具栏「从 URL 导入」，支持多行批量；后端 /api/url/open 逐条解析(yt-dlp)，Referer 按 URL host 生成；优先 audio-only 直链，无则下载完整文件提取；无单文件视频流降级仅音频；需登录/DRM 明确报错。
- 总览条播放头：在总览条(minimap)上显示红色播放头线 + 时间码；点击/拖动跳转播放位置，与主播放器同步。
- Ctrl+→ 多选快进：按一次标记一段选区（橙色）并前进，连续按累积多段；Ctrl+← 撤销上一段。「播放选区」顺序试听全部标记段，「加片段」一次全部加入；右键或普通拖选清空多选。

工作区（Blender 式自由排版）：
- 拖面板标题栏（.panel-grip）可在 5 个槽位间交换面板；松开到空白处即取消
- 拖分隔条调整各面板行/列大小；最小宽度/高度自动钳制
- 面板右上角 × 或「窗口▸面板开关」显隐；隐藏后其余面板伸展；「窗口▸恢复默认布局」还原
- 布局自动保存到 localStorage（vc.workspace.v1），刷新后还原
- 传输栏固定在窗口底部（状态栏上方），不参与面板排列

## 4d. 项目式工作区（多视频共享角色池）

- 工具栏「项目」下拉快速切换项目；「文件▸新建/重命名/删除项目」管理项目；删除非空项目被拒。
- 素材列表 / 片段列表 / 角色池 / 训练集导出均为项目级：片段表跨素材聚合并带「来源素材」列；角色池聚合项目内全部素材的片段；导出训练集把项目内全部片段按序写入同一目录（speaker 用角色名）。
- 每个素材仍单独存储片段与说话人分段（时间轴相对该素材）；角色池（含代表声纹 embedding/emb_count）为项目级共享。
- 项目/素材注册表与项目池存入 SQLite `voicecut.db`；旧版每素材角色池自动并入「默认项目」，标签加素材前缀。

## 5. 数据流（纯浏览器前后端分工）

```
浏览器(HTML + wavesurfer.js v7)        Python 后端 (Flask)
───────────────────────                ──────────────────────
波形/缩放/选区/总览        ◄─peaks───   ffmpeg 解码 + 波形峰值计算
播放/循环(本地解码)        ◄─audio────   WAV Range 流式服务
拖拽导入/按钮/快捷键        ──req───►   /api/import /denoise /separate /transcribe /dataset
项目/素材/角色池            ◄─json────   /api/projects /api/items /characters
B站链接打开                ──req───►   yt-dlp 解析 + Range 代理 + 边播边缓存
视频预览窗                 ◄─video────   预览 MP4 (无损转封装, Range 流)
```

浏览器**做不到**、必须交给后端的能力：
- 视频容器解码（MKV/AVI/FLV/MP4）→ ffmpeg 抽音频 / 转封装预览
- 任意音频格式（FLAC/OGG/AAC…）→ 转 WAV
- DSP：降噪 / 分离 / 去静音 / 响度标准化
- 把选区写入目标目录 → ffmpeg 导出
- B 站防盗链流（Referer + 签名 URL）→ 后端代理

## 6. 关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| GUI 形态 | 纯浏览器 (127.0.0.1:8765) | 波形体验天花板最高（wavesurfer）、零打包、拖拽/快捷键天然 |
| 波形引擎 | wavesurfer.js v7（本地 vendor） | 选区/缩放/播放/循环内置且经过产品验证；离线可用 |
| 音频内部格式 | 48kHz 单声道 PCM WAV | 处理与播放的统一工作格式；训练集导出再转 32k |
| 导出采样率 | WAV 32k 单声道（训练集）/ 44.1k / 48k 可选 | 对齐 GPT-SoVITS 标准 |
| 降噪策略 | 保守（prop_decrease 默认 0.75，stationary） | 过度降噪损伤音色；宁可留轻微底噪 |
| 人声分离 | demucs htdemucs --two-stems=vocals, GPU | RTX 5060 Ti (Blackwell) 快 5~10 倍 |
| B 站方案 | 方案 A：免登录 480p 单文件 MP4 直链代理 | 秒开可拖动；720p+ 需 cookie，留扩展口 |
| 片段校验 | 时长/静音率/爆音/空文本 标红，不自动剔除 | 主观听感（背景声/残响）交给人耳判断 |
| 素材管理 | 处理产物均为新素材条目，保留溯源 | 分离/降噪结果可对比、可回退 |
| 素材组织 | 项目式：素材挂项目下，角色池项目级共享 | 多视频统一角色池、一套训练集 |

## 7. 已知限制（如实记录）

- B 站免登录通常仅 360p/480p；720p+ 需 SESSDATA cookie（扩展点）
- B 站签名 URL 约 2 小时过期，长会话需重新解析
- 歌曲/广播剧分离后人声轨可能残留 BGM 残响 → 靠人工挑选 BGM 轻的片段
- faster-whisper 首次使用需下载模型（medium ≈1.5GB，large-v3 ≈3GB）
- demucs 首次分离需下载 htdemucs 模型（≈300MB）
