      从 URL 导入

      支持 B 站 / YouTube / 腾讯 / 优酷 / 爱奇艺 / Vimeo / 抖音 / 快手等（每行一个，可批量）。 导入后在后台自动下载：先取音频（很快就能剪辑），再下完整视频并生成本地预览，此后播放不再依赖网络。 免登录通常仅低清晰度；需登录 / DRM 的内容会明确报错。

      自动切分（按静音）

      检测静音并切出片段，完成后将替换当前素材的全部片段（会先确认）。

      批量转写（日语）

      对片段列表逐条转写并回填文本。仅处理文本为空的片段。

      导出训练集（GPT-SoVITS）

      生成 001.wav + 001.txt + list.txt，32kHz 单声道，自动去静音 + 响度标准化；空文本/过短片段跳过。list.txt 按清晰度分数降序排列（高分片段优先）。

      导出选区

      导出当前选区 [] 为独立文件。
